# دفتر الحساب — تطبيق أندرويد

تم تحويل صفحة الويب إلى **مشروع أندرويد أصلي كامل** (وليس مجرد اختصار للمتصفح):

- أيقونة تطبيق حديثة (Adaptive Icon) بتصميم "دفتر مفتوح + ختم ذهبي" بألوان التطبيق الأصلية (كحلي #16222B وذهبي #AD7E2C)، تدعم الشكل الدائري/المربع/المتحرك حسب هاتف المستخدم، بالإضافة لنسخة أحادية اللون لأندرويد 13+.
- شعار مستقل بصيغة SVG (`logo.svg`) بجودة عالية يصلح للاستخدام في متجر Google Play أو أي مكان آخر.
- شاشة بدء تشغيل (Splash Screen) بنفس هوية التطبيق.
- تم **إصلاح حفظ البيانات**: الكود الأصلي كان يعتمد على نظام تخزين خاص بمعاينة Claude (`window.storage`) لن يعمل خارجها، فتم استبداله بـ `localStorage` ليعمل التطبيق ويحفظ بياناتك فعليًا على الجهاز بشكل مستقل.
- تم ربط أزرار "تصدير PDF" و"مشاركة صورة" و"تنزيل" بواجهة أندرويد أصلية (Native Bridge) بحيث تُحفظ الملفات فعليًا في مجلد التنزيلات، وتفتح قائمة المشاركة الحقيقية لأندرويد.
- شريط الحالة والتنقل بلون كحلي متناسق، وزر الرجوع في أندرويد يتعامل بذكاء مع النوافذ المنبثقة والتنقل داخل التطبيق بدل إغلاقه مباشرة.

## هيكل المشروع

```
LedgerApp/
  app/
    src/main/
      java/com/ledger/daftar/MainActivity.java   ← الكود الأصلي (WebView + الجسر الأصلي)
      assets/www/index.html                        ← تطبيقك (نفس الكود، بعد إصلاح الحفظ والتصدير)
      res/drawable/ic_launcher_foreground.xml       ← رسمة الشعار (دفتر + ختم)
      res/drawable/ic_launcher_background.xml       ← خلفية الأيقونة الكحلية
      res/mipmap-anydpi-v26/ic_launcher.xml         ← تعريف الأيقونة التكيّفية
      AndroidManifest.xml
  logo.svg                                          ← الشعار كملف مستقل عالي الجودة
```

## المتطلبات على اللابتوب

1. **Android Studio** (أحدث إصدار) — نزّله من: https://developer.android.com/studio
2. لا تحتاج لتثبيت Java يدويًا؛ Android Studio يأتي مزودًا بكل ما يلزم (JDK وGradle).
3. اتصال إنترنت عند أول فتح للمشروع (لتنزيل مكتبات Gradle) وعند تشغيل التطبيق (الخطوط من Google Fonts ومكتبتا html2canvas وjsPDF تُحمَّل من الإنترنت داخل التطبيق نفسه، تمامًا كما في نسخة الويب الأصلية).

## خطوات التشغيل خطوة بخطوة

1. افتح **Android Studio**.
2. من الشاشة الرئيسية اختر **Open** (فتح مشروع)، ثم حدد مجلد `LedgerApp` بالكامل (المجلد الذي بداخله `settings.gradle`).
3. انتظر حتى ينتهي **Gradle Sync** أول مرة (شريط تحميل أسفل النافذة) — قد يستغرق دقائق حسب سرعة الإنترنت.
4. لتجربة التطبيق:
   - **على جهاز حقيقي**: فعّل "خيارات المطورين" و"تصحيح USB" في هاتفك، وصله بالكابل، سيظهر اسمه في القائمة أعلى الشاشة بجانب زر التشغيل (▶) — اختره ثم اضغط ▶.
   - **على محاكي (Emulator)**: من القائمة Tools → Device Manager → Create Device، اختر أي جهاز (مثلاً Pixel 7) ونظام أندرويد حديث، ثم شغّله واضغط ▶ في Android Studio.
5. سيُثبَّت التطبيق باسم **"دفتر الحساب"** وبأيقونته الجديدة على الشاشة الرئيسية للجهاز/المحاكي.

## لإنشاء ملف APK لتثبيته يدويًا على أي هاتف

من القائمة العلوية:
```
Build → Build Bundle(s) / APK(s) → Build APK(s)
```
بعد الانتهاء ستظهر رسالة أسفل يمين الشاشة فيها رابط **locate** يفتح مجلد الملف الناتج
(المسار عادة: `app/build/outputs/apk/debug/app-debug.apk`).
انسخ هذا الملف لهاتفك وثبّته مباشرة (فعّل خيار "تثبيت من مصادر غير معروفة" إن طُلب منك).

> هذه نسخة "Debug" جاهزة للتجربة الشخصية والتوزيع المباشر. إذا أردت لاحقًا نشره على Google Play، يلزم عمل "Signed Bundle/APK" بمفتاح توقيع خاص بك (يمكنني مساعدتك في ذلك عند الطلب).

## تخصيص لاحق سريع

- **اسم التطبيق**: عدّل القيمة في `app/src/main/res/values/strings.xml`.
- **الألوان**: عدّل `app/src/main/res/values/colors.xml`.
- **الشعار/الأيقونة**: عدّل ملفي `ic_launcher_foreground.xml` و`ic_launcher_background.xml`، أو استبدلهما بالكامل عبر: كليك يمين على `res` → New → Image Asset، واستورد `logo.svg` مباشرة إن أردت تصميمًا مختلفًا بسهولة داخل الأداة الرسومية لأندرويد ستوديو.
- **محتوى التطبيق نفسه** (الشاشات والوظائف): كله داخل `app/src/main/assets/www/index.html` — هو نفس الكود الذي أرسلته، ويمكنك تعديله بأي محرر نصوص عادي دون الحاجة لإعادة فتح أندرويد ستوديو، فقط أعد التشغيل (▶) بعد الحفظ.

## ملاحظة مهمة حول البيانات

بيانات كل عامل ودفعاته تُحفظ الآن محليًا على الجهاز نفسه (`localStorage` داخل تطبيق أندرويد المعزول)، أي أنها **خاصة بهذا الجهاز فقط** ولا تُزامَن تلقائيًا مع أي جهاز آخر. عند حذف التطبيق أو بياناته من إعدادات أندرويد ستُفقد البيانات المحفوظة، لذا يُنصح باستخدام زر "تصدير" داخل التطبيق دوريًا لحفظ نسخ PDF احتياطية في مجلد التنزيلات.
